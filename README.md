# MinSpec Workbench Fixtures

Dev-only fixture profiles for MinSpec Workbench package and app testing.

This repository is part of the MinSpec incubation surface.

## Status

Incubating.

This repository is publicly visible but not publicly governable. Unsolicited pull requests, code changes, fixture submissions, workflow changes, dependency changes, documentation rewrites, and package mutations are not accepted during incubation.

All repository authority is currently retained by the maintainer.

## Purpose

`minspec/workbench-fixtures` is intended to provide a centralized dev-only fixture profile registry for Workbench.

Fixture profiles are expected to be requirements-gated:

- installed package/component
- available fixture profile
- explicitly enabled profile

Missing requirements should be visible and non-fatal.

## Source authority

The GitHub repository is the source of truth.

Do not rely on copied snippets, unofficial patches, generated code, or third-party pull requests as source authority.
