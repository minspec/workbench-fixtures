# Contributing

MinSpec is in incubation.

This repository is publicly visible, but outside contributions are not accepted at this stage.

Please do not open unsolicited pull requests for:

- code
- fixtures
- package metadata
- workflows
- dependency changes
- documentation rewrites
- generated files
- agent-produced patches

Unsolicited pull requests may be closed without review.

Security-sensitive concerns should be handled through GitHub’s security reporting features if available.
